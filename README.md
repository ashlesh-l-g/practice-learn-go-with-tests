# Learning Go with Tests

A hands-on repository for learning **Go (Golang)** through practical examples and test-driven development.

This repository is based on [Learn Go with Tests](https://github.com/quii/learn-go-with-tests), with implementations, experiments, and notes written while learning Go.

The goal is to understand not only Go syntax, but also how to write **idiomatic, maintainable, and testable Go code**.

---

## 🎯 Goals

- Learn Go fundamentals through practical exercises
- Build a strong understanding of Go's testing ecosystem
- Practice Test-Driven Development (TDD)
- Understand pointers, structs, methods, and interfaces
- Learn dependency injection and loose coupling
- Practice table-driven tests
- Write idiomatic Go
- Gradually progress toward production-oriented Go development

---

## 📚 Topics

The repository currently covers:

- Hello World
- Integers
- Iteration
- Arrays & Slices
- Maps
- Pointers
- Error Handling
- Structs
- Methods
- Interfaces
- Table-Driven Tests
- Dependency Injection

More topics will be added as I progress through Go.
